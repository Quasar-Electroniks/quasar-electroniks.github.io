# Quasar Electroniks — Website

Recovered from the owner-provided browser HAR export on 2026-11-03.

## Contents
- `index.html`: original site HTML (ChatGPT editor overlay removed)
- `styles-v3.css`: original styles
- `sphere.js`: original interactive sphere and project navigation
- `weather.js`: local weather widget using browser geolocation and Open-Meteo
- PNG images: original site assets

## Publish
Upload all files to the root of the `main` branch of `Quasar-Electroniks/quasar-electroniks.github.io`.
In GitHub Settings → Pages select Deploy from a branch → `main` → `/ (root)`.

## Notes
- Links to individual projects are currently placeholder anchors and need real destinations.
- Weather requires browser geolocation permission; if declined it shows a fallback.
- The original site's ChatGPT-specific editing overlay has been removed.
- Fonts are loaded from Google Fonts.
- No HAR headers, cookies, or authentication data are included in this recovered package.
